<details><summary>展开两版输出原文</summary>

**无约束提示输出**

```text

```

**精细提示输出**

```text
【分别证明充分性与必要性】结论：A 可逆是 Ax=0 只有零解的**充分必要条件（充要条件）**。
  "必要不充分"的判断错误。

【必要性】已知 Ax=0 只有零解，证明 A 可逆。
  设 Ax=0 的解空间（零空间）为 N(A)。由已知 N(A) = {0}，故 dim N(A) = 0。
  由秩-零化度定理：rank(A) + dim N(A) = n ⇒ rank(A) = n ⇒ A 满秩 ⇒ A 可逆。∎

【充分性】已知 A 可逆，证明 Ax=0 只有零解。
  设 x 满足 Ax=0，两边左乘 A⁻¹：A⁻¹Ax = A⁻¹0 ⇒ x = 0，故只有零解。∎

【等价链条（可一并记忆）】对 n 阶方阵 A，以下命题两两等价：
  A 可逆 ⇔ |A| ≠ 0 ⇔ rank(A) = n ⇔ Ax=0 只有零解 ⇔ Ax=b 有唯一解 ⇔ A 的列向量线性无关
  ⇔ A 与单位矩阵等价 ⇔ 0 不是 A 的特征值。

【常见错因】把"可逆"当成只保证"解存在"（那是 Ax=b 有解的条件），于是误判为"必要不充分"；
  根源是没有区分"解的存在性"与"解的唯一性"。

【不确定标注】以上结论对方阵成立；若 A 不是方阵，则 Ax=0 只有零解只说明列满秩，
  不能谈"可逆"（此时考虑左逆），属于超出本题前提的情形。
```

- **输入提示**：函数在一点可导是否一定能推出它在该点连续？反之连续是否一定可导？请给出判断与反例。

- **精细提示**：已合规（命中模式：无）
- **分析结论**：要求给出双向判断与反例，避免把「可导⇒连续」误扩为等价

<details><summary>展开两版输出原文</summary>

**无约束提示输出**

```text

所以连续也一定能推出可导，这两个条件是等价的，考试里可以直接互相使用。
```

**精细提示输出**

```text
【错误定位】本题属概念关系辨析题，需要分别判断"可导 ⇒ 连续"与"连续 ⇒ 可导"两个方向的真假。
【错误类型】概念混淆（把充分条件误当必要条件，或把两个方向混为一谈）。
【根因分析】根源是把"连续"与"可导"当成等价条件。事实上可导是更强的条件：
  可导蕴含连续，但连续只保证曲线不断开，不保证没有"尖点"。

【正确的双向判断】
  方向一：可导 ⇒ 连续 —— 成立。
    证明：若 f 在 x₀ 可导，则 lim(x→x₀)[f(x) − f(x₀)]/(x − x₀) = f'(x₀) 存在，
    于是 f(x) − f(x₀) = (x − x₀) · [f(x) − f(x₀)]/(x − x₀) → 0 · f'(x₀) = 0，
    即 lim f(x) = f(x₀)，故 f 在 x₀ 连续。
  方向二：连续 ⇒ 可导 —— 不成立。
    反例：f(x) = |x| 在 x = 0 处连续，但左右导数分别为 −1 与 +1，
    lim(x→0)[|x| − 0]/(x − 0) 不存在，故在 x = 0 处不可导（这就是典型的"尖点"）。

【关联知识点】导数定义、连续定义、左右导数、一元函数可导与可微的等价性。
【同类练习（只给思路提示）】
  1) 判断 f(x) = x^(1/3)（立方根）在 x = 0 处是否连续、是否可导。
     —— 提示：考察差商极限是否有限。
  2) 是否存在"处处连续但处处不可导"的函数？
     —— 提示：魏尔斯特拉斯函数，属超纲了解即可。
【预防措施】遇到"是否一定"类提问，先写出两个方向的蕴涵式，再逐个找反例，不要凭直觉作答。
【不确定标注】"连续不一定可导"是标准结论，无争议；"处处连续处处不可导"的存在性证明超纲，
  此处仅作了解，标注【超纲，仅了解】。
```

</details>
