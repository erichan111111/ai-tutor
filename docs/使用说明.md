## 1. 环境要求

- Windows / macOS / Linux 均可
- Python 3.10 或更高（开发环境为 CPython 3.12）
- **不需要安装任何第三方包，不需要联网**

确认 Python 可用：

```powershell
python --version
```

如果系统里的 `python` 指向别处，直接使用绝对路径调用即可，例如：

```powershell
& "C:\Users\Eric\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" -m ai_tutor selftest
```

## 2. 三种使用方式

### 2.1 一键自检（先跑这个）

```powershell
cd D:\project
python -m ai_tutor selftest
```

会依次验证 44 项：提示词库完整性 → 六大模块输出合规 → 提示词一致性 →
风险用例判定 → 报告落库 → 会话持久化 → 任务路由 → 运行报告。
**预期输出结尾**：`自检结果：36/36 项通过　✅ 全部通过`。

### 2.2 Web 界面（推荐演示方式）

```powershell
python -m ai_tutor web --open
```

浏览器打开 `http://127.0.0.1:8848`。五个页签：

| 页签 | 用途 |
| --- | --- |
| 答疑工作台 | 选模块 → 提问 → 看答案 + 质检指标 + 可展开的提示词原文 |
| 提示词库 | 五要素方法论、六种结构模式、每模块的精细提示原文 |
| 风险实证 | 一键执行四类测试，看量化对比表与改进建议 |
| 会话与记录 | 回看历史会话（含每轮提示词与输出）、评测批次、运行报告 |
| 项目说明 | 三阶段要点、运行状态、任务路由表、命令行入口 |

停止服务：在终端按 `Ctrl+C`。

### 2.3 命令行

```powershell
python -m ai_tutor status                                   # 运行状态
python -m ai_tutor models                                   # 模型与可用性
python -m ai_tutor ask "帮我解释一下递归是什么" --module M4   # 单次提问
python -m ai_tutor chat --module auto                        # 交互式多轮
python -m ai_tutor plan --subject 高等数学 --days 5          # 一键生成复习计划
```

`chat` 交互模式内置命令：

```text
:image <路径>    附加图片（可多张，:clear 清空）
:module M3       切换模块
:router          开关任务路由（按任务类型自动选模型）
:prompt          查看上一次实际发送的提示词全文
:json            开关 JSON 原始结果输出
:session         打印当前会话的完整记录
:quit            退出（会话自动保存到数据库）
```

## 3. 六个功能模块怎么用

### M1 习题解析

```powershell
python -m ai_tutor ask "帮我解这道题：lim(x→0) (sin x - x) / x³" --module M1 --show-prompt
```

会输出六段式解析：题型判断 → 方法选择 → 分步求解 → 交叉验证 → 易错点 → 不确定标注。
`--show-prompt` 可同时看到实际发送的提示词原文（用于验收提示词工程）。

题干过短时模块会先追问，而不是硬解。

### M2 知识框架生成

```powershell
python -m ai_tutor ask "帮我整理一下 TCP 协议的知识点" --module M2
```

输出四级分层 + 考点星级（★★★/★★/★）+ 三张对比表 + 常见误区 + 超纲标注 + 复习周期建议。

### M3 错题归纳

```powershell
python -m ai_tutor ask "帮我分析一下这个错题：这道题我第 2 步把 cos x − 1 直接替换成了 0" `
  --module M3 --student-answer "第1步：原式=0/0型。第2步：cos x − 1 ≈ 0，所以分子为 0…"
```

七步诊断 + 错误类型五分类（概念/计算/审题/方法/盲区）。
**不提供学生解答时会先追问**，不会凭空猜错因。

### M4 概念通俗讲解

```powershell
python -m ai_tutor ask "帮我解释一下递归是什么" --module M4 --level 零基础
```

九段式：生活类比（禁用「俄罗斯套娃」等俗套例子）→ 技术定义 → 结构图解 →
代码逐行注释 → 执行过程表 → 关键三要素 → 初学者误区 → 不确定/争议标注。

### M5 薄弱检测与复习计划（两阶段）

```powershell
# 第一阶段：只出 5 道诊断题，明确声明"未诊断不下发计划"
python -m ai_tutor ask "帮我做个高等数学的复习计划，还剩 5 天" --module M5

# 第二阶段：把作答贴回去，才生成按天计划
python -m ai_tutor ask "帮我做个高等数学的复习计划，还剩 5 天" --module M5 `
  --stage plan --answers "D1 可微定义……D5 用拉格朗日乘数法解出 x=y=5，最大值 25"
```

计划会写明薄弱点时间占比（要求 ≥40%）、每日「内容 / 练习 / 自测 / 达标标志」四栏、
以及 1 次限时模拟自测。程序会自动核对占比是否达标并在不达标时给出 ⚠ 提示。

非交互生成（跳过诊断）：

```powershell
python -m ai_tutor plan --subject 高等数学 --days 5 --weak 可微性判别 抽象函数漏项 --out plan.md
```

### M6 口语背诵陪练（逐轮闭环）

```powershell
# 第 1 轮：出题 + 评分维度说明
python -m ai_tutor ask "陪我练一下计算机网络三次握手的背诵" --module M6

# 第 2 轮：提交你的作答，会先给上一轮四维评分，再给本题
python -m ai_tutor ask "陪我练一下计算机网络三次握手的背诵" --module M6 `
  --reply "三次握手是 SYN、SYN+ACK、ACK。两次的话服务器不知道客户端有没有收到，会浪费资源。"
```

四维评分（准确性/流畅度/完整度/逻辑性，各 25 分），5 轮后输出总分、进步点、改进点。
Web 界面里连续对话更直观（会话状态自动保存）。

## 4. 图片输入

题目照片、截图、手写演算都可以直接传给助手，程序会自动选用支持视觉的模型
（当前为 `deepseek-flash`）识别图片内容，再按模块要求解析。

```powershell
# 单张
python -m ai_tutor ask "识别图片里的题目并按模块解析" -i 题目.png

# 多张（例如题目 + 自己的演算过程）
python -m ai_tutor ask "看看我的演算错在哪" -i 演算.jpg -i 题目.png

# 目录 / 通配符
python -m ai_tutor ask "批改这些题" -i shots\
python -m ai_tutor ask "批改这些题" -i "题目*.png"
```

Web 界面支持**点击选择、拖拽到虚线框、Ctrl+V 直接粘贴截图**（最多 4 张，单张 ≤ 8 MB）。

限制可在 `config.json` 的 `image` 段调整：

```json
"image": { "enabled": true, "max_images": 4, "max_bytes": 8388608,
           "allowed_types": ["png", "jpg", "jpeg", "webp", "gif"] }
```

> 识别不清的地方（模糊、缺角、笔迹难辨）会被明确写进【不确定标注】，
> **不会**凭猜测补全题目条件——这是提示词里的硬性契约。

输出：

- 两版输出全文 + 各自的结构/诚实/教学分
- 差值表：字符数、结构完整度、不确定标记、教学价值
- 相似度：2-gram Jaccard / LCS 占比 / 结构相似度 / 综合

批量处理（JSONL，每行一条）：

```powershell
# cases.jsonl
# {"question": "帮我解这道题：lim(x→0)(sin x - x)/x³", "module": "M1", "mode": "fine"}
# {"question": "帮我整理一下 TCP 协议的知识点", "module": "M2"}
# {"question": "识别图片里的题目", "module": "M1", "image": "D:/题.png"}
python -m ai_tutor batch cases.jsonl --out results.jsonl
```

## 5. 做风险实证（阶段三）

```powershell
python -m ai_tutor risk list                              # 全部用例一览
python -m ai_tutor risk show H2                            # 单个用例详情（风险正则/合规信号）
python -m ai_tutor risk run --kind pair                    # 事实幻觉 + 逻辑缺陷（含消融对照）
python -m ai_tutor risk run --kind repetition --rounds 3    # 同质化（含反同质化对照）
python -m ai_tutor risk run --kind comparison               # 多工具横向对比
python -m ai_tutor risk run --kind all --outdir data/reports
```

每个报告包含：量化对比表、关键发现、改进建议、逐条记录（提示词原文 + 输出原文）。
报告同时写入 SQLite，可在 Web 的「会话与记录 → 评测批次」中查看。

**多工具对比需要真实 Key**。配置后（见第 7 节）：

```powershell
python -m ai_tutor risk run --kind comparison --models openai anthropic qianfan
```

未配置的模型会被明确列出并说明原因，不会静默跳过或伪造数据。

# 生成阶段三风险实证的图解、Excel 记录表与图文报告
python -m ai_tutor report assets --mode auto                  # 有 Key 就实测，否则离线复现
python -m ai_tutor report assets --mode online                # 强制真实模型实测
python -m ai_tutor report assets --mode offline               # 离线复现（不消耗额度）

## 7. 接入真实模型

### 方式一：环境变量（推荐，优先级最高）

```powershell
$env:OPENAI_API_KEY    = "sk-..."
$env:ANTHROPIC_API_KEY = "sk-ant-..."
$env:QIANFAN_API_KEY   = "..."
$env:QIANFAN_SECRET_KEY= "..."

# 切换默认模型
$env:AI_TUTOR_MODEL = "openai"     # 或 deepseek / anthropic / qianfan / ollama
python -m ai_tutor ask "帮我解释一下递归是什么"
```

### 方式二：编辑 config.json

```json
{
  "llm": {
    "default": "deepseek",
    "models": {
      "deepseek": { "model": "deepseek-chat", "api_key": "sk-你的key", "base_url": "https://api.deepseek.com/v1" }
    }
  }
}
```

### 支持的提供方

| 提供方 | `provider` 名 | 协议 | 说明 |
| --- | --- | --- | --- |
| OpenAI | `openai` | OpenAI 兼容 | GPT-4o，阶段三主模型 |
| Anthropic | `anthropic` | 原生 Messages | Claude 3.5 Sonnet，事实核查首选 |
| 百度千帆 | `qianfan` | 千帆 v2 | 文心一言 4.0 |
| DeepSeek | `deepseek` | OpenAI 兼容 | — |
| 通义千问 | `dashscope` | OpenAI 兼容 | — |
| 智谱 GLM | `zhipu` | OpenAI 兼容 | — |
| Kimi | `moonshot` | OpenAI 兼容 | — |
| 硅基流动 | `siliconflow` | OpenAI 兼容 | — |
| 本地 Ollama | `ollama` | OpenAI 兼容 | `api_key` 填任意非空值，需先 `ollama serve` |
| 内置离线 | `mock` | — | 默认，无需任何配置 |

### 任务路由（阶段三「工具路由」建议）

```powershell
python -m ai_tutor routes                              # 查看路由表
python -m ai_tutor ask "列出 3 篇 2023 年关于 EDTA 的 SCI 论文" --router
```

路由规则：事实核查 → Claude（幻觉率最低）；结构化提纲 → GPT-4o（结构最完整）；
中文口语化讲解 → 文心一言；逻辑类 → 低温度 + 「先举反例」红线。

> **关键点**：即使问题出现在"知识框架"这类内容模块里，只要文本里出现
> 文献 / DOI / 页码 / 政策等信号，任务路由也会改走**事实核查**模型——
> 避免模型被"整理成框架"的格式指令带着去编造出处。

## 8. 数据在哪、怎么重置

- 数据库：`D:\project\data\ai_tutor.db`（SQLite）
- 风险测试报告：`D:\project\data\reports\*.md` / `*.json`
- 日志目录：`D:\project\data\logs`（预留）

重置：删除 `data\` 目录即可，下次运行自动重建。

```powershell
Remove-Item -Recurse -Force D:\project\data
```

改数据目录：`config.json` 的 `app.data_dir`，或环境变量 `AI_TUTOR_DATA_DIR`。

## 9. 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 输出里出现 `⚠ 已自动降级到离线模型` | 远端调用失败（Key 错误/网络/限流）。看 `degraded_reason` 字段；修好后自动恢复 |
| 显示 `离线模拟输出` 徽标 | 当前用的是内置模型。配置 Key 后自动切换 |
| Web 打不开 | 端口被占用，换端口 `--port 9000`；或确认服务已启动、终端未关闭 |
| 中文显示乱码 | 终端编码问题：`chcp 65001`，或 `$env:PYTHONIOENCODING="utf-8"` |
| `ModuleNotFoundError: ai_tutor` | 必须在 `D:\project` 目录下运行，或 `$env:PYTHONPATH="D:\project"` |
| 想看完整报错堆栈 | `$env:AI_TUTOR_DEBUG="1"` 后再运行 |
| 自检某项失败 | 输出会给出该项的实测值（如"段落=3/6"），据此定位到对应模块的提示词或输出 |
