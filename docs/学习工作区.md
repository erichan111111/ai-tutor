# 学习工作区 · v1.2.0

产品主线是「今天做什么 → 卡在哪里 → 怎样记住 → 下次再练」。使用者是有明确考试范围、希望自己掌握知识的大学生。默认个人、本地使用。

## 一次完整的复习

1. 启动 `python -m ai_tutor web --open`。没有密钥也能管理课程和学习记录；页面会明确提示答疑为离线演示。
2. 在「今日学习」添加第一门课程。填写名称、考试日期、每天能投入的分钟数、目标，以及每行一个的复习主题。
3. 在「课程与计划」点击「安排复习任务」。每个主题生成梳理、练习、闭卷自测三个任务；默认估时分别为 20/25/15 分钟，低于该时长的每日预算会缩短单次任务。排程会考虑课程中已有的未完成自定义任务。
4. 从任务点击「去学习」，会带上课程背景与建议提问。提问内容可编辑，点击发送才调用模型。完成学习后自己勾选任务，也可以撤销。
5. 在回答下点击「存为复习卡片」，用自己的话记录错因或重点。参考回答来自数据库中的原始轮次，演示/降级来源无法由前端改写；同一回答重复保存不会创建重复卡片。
6. 打开「笔记与复习」，先写下自己的回忆，再揭晓参考答案，自评后安排下一次提醒。
7. 下次打开页面，会恢复上次会话。首页给出当天及逾期任务、待复习卡片和考试倒计时。

## 计划的含义

计划按课程中的每天预算顺序排程，不会假称知道学生的弱点或客观掌握程度。
如果范围太大，部分任务可能排在考试之后，页面会提醒调整；不会悄悄压缩成一个不可能完成的计划。
课程预算相互独立，多门课程的总时长需要自行协调，首页会汇总待学时长。

反复点击安排不会重复生成或清空已完成任务。可以添加自定义任务、调整具体日期、标题与时长、撤销完成。
修改课程目标不会自动重写已有任务，避免丢失自己的安排；请按新范围添加任务并调整日期。
归档会暂停该课程的首页任务和卡片提醒，课程及原始记录仍可查看，恢复后继续提醒。

## 卡片与自评

支持手写问题/参考答案，也支持把答疑回答保存成卡片。卡片提供搜索、课程筛选、只看待复习、错因编辑、回到原始会话及删除。
每张卡片每天记录一次自评：

| 自评 | 下次复习 |
| --- | --- |
| 还不会 | 1 天后，间隔重置 |
| 有点难 | 2 天后 |
| 已掌握 | 首次 3 天后；后续按上次间隔翻倍，最多 60 天 |

这是一个透明的提醒规则，不是经过验证的记忆预测或客观评分。卡片里的临时回忆文本只用于本次练习，不会保存；需要留下的内容请写进「复习重点」。
笔记上的「离线演示 · 待核对」与降级标记会持续显示。不要用演示答案替代教材或独立验证。
原有 M6 的四维预评分也只是术语/长度等规则近似，尤其不能用于任意学科的客观成绩判定。

## 会话、失败与数据

课程答疑会把目标、范围和日期作为模型学习背景。会话固定归属一个课程，切换课程会开始新会话。
恢复会话后会传递最近六轮完整问答。服务器保存完整历史，界面可以回到旧会话继续学习。
问题草稿与上次会话编号存在浏览器本地存储；浏览器禁用本地存储时仍可通过会话记录恢复。
生成时暂停修改当前问答设置；请求失败后保留原问题与图片，方便检查后再发送。

课程、任务、会话、卡片与自评保存到 `data/ai_tutor.db`，启动时自动增加学习数据表，不改写已有会话。
「笔记与复习 → 导出学习数据」导出 JSON，含课程、任务、笔记、自评及完整会话（不会截成前 200 轮），不含模型配置或 API Key。
导出是可读的数据快照；当前没有界面导入功能。完整迁移可先停止服务，再复制 `data/` 目录到新机器。
删除卡片会同时删除它的自评，原始会话不受影响；操作前界面会确认。

接入在线模型时，问题、最近会话、课程背景和图片会发送到模型服务。密钥只在服务器本地读取，不在前端填写。
默认只监听 `127.0.0.1`；当前没有登录或多用户隔离，不应直接作为公网服务部署。
页面拒绝跨站写入；HTTP API 的脚本调用不受浏览器 Origin 限制。

## 学习 API

所有 POST 请求均为 JSON 对象；日期为 `YYYY-MM-DD`。页面使用浏览器当地日期发送 `today`，脚本省略时使用服务器当地日期。
非法字段返回 400，不存在的记录返回 404。

| 方法与路径 | 内容 |
| --- | --- |
| `GET /api/study?today=2026-10-12` | 课程、任务、笔记、今日待办及统计 |
| `GET /api/study/export` | 完整学习数据 JSON |
| `POST /api/study/course` | 创建/编辑：`id?`, `name`, `exam_date`, `daily_minutes`, `goal`, `topics` |
| `POST /api/study/archive` | `course_id`, `archived`（布尔值） |
| `POST /api/study/plan` | `course_id`, `today?`；返回 tasks、warning、basis |
| `POST /api/study/task` | `course_id`, `title`, `due_date`, `minutes` |
| `POST /api/study/task/update` | `id`, `done?`（布尔值）, `due_date?`, `title?`, `minutes?` |
| `POST /api/study/note` | `title`, `course_id?`, `reflection?`, `source_turn_id?`, `today?`；手写需 `question`, `answer` |
| `POST /api/study/note/update` | `id`, `title`, `reflection` |
| `POST /api/study/note/delete` | `id` |
| `POST /api/study/review` | `note_id`, `rating`（again/hard/good）, `today?` |
| `POST /api/ask` | 保留原参数，新增可选 `course_id` |

## 产品验收与当前边界

可复现验收：新增课程、生成计划、完成/撤销任务、保存同一回答两次、揭晓并自评、重启后查看、归档恢复、导出完整记录。
回归测试使用临时 SQLite 与离线模型，不消耗真实模型额度。现有自检与图片链路继续保留；CI 覆盖 Python 3.10/3.14。

当前完成的是个人本地学习产品闭环。尚未提供云同步、多人账户、推送通知、教材检索、自动验证答案或已验证的掌握度诊断。
提醒在打开页面时更新，跨天持续开着的页面需点击「刷新」。在线教学效果需用真实模型与学生试用进一步评估。
